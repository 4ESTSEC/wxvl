## 工具介绍  
  
AI 赋能的漏洞播报系统，AI 根据公开的漏洞思路自动生成 PoC、漏洞简介、漏洞原理、攻击范围，自动落库存储nuclei格式，24 小时监控全网漏洞播报，间隔10分钟自动抓取。

## 特性  
- **多源聚合**  
 — 并发抓取 Seebug、先知、Exploit-DB 的 RSS 与正文，单源失败不影响整体，每个请求有硬性超时。  
  
- **自助接入新社区**  
 — 设置页填一个社区地址，系统自动探测其 feed 并由 AI 判断是否为漏洞社区，确认后落配置即抓。  
  
- **AI 补全**  
 — LLM 将文章转为结构化情报：名称、简介、原理、攻击范围；文章已含 PoC 则原样收录，缺失则按公开思路补写 Python PoC。  
  
- **双向 nuclei 通道**  
 — 收录的漏洞可导出为 nuclei v3 模板；上游模板库的新增模板也可增量同步入库。  
  
- **自动中文化**  
 — 英文情报与模板元数据经 LLM 译为中文，CVE 编号、组件名、函数名保留原文。  
  
- **文件式存储**  
 — 无数据库依赖，每条漏洞一个目录，换库只改 store.py  
。  
  
- **内置 Web 控制台**  
 — 漏洞列表、详情、模板库、在线设置，定时后台刷新并展示倒计时。

## nuclei 双向通道  
  
**导出**  
 — 把收录漏洞的原理、影响与 PoC 转成 nuclei v3 模板。详情页可单条重新生成，也可通过接口触发；默认只产出只读探测模板。  
```
curl -X POST localhost:8100/api/vulns/<ID>/nuclei \  -H 'Content-Type: application/json' -d '{"allow_write": false}'
```  
  
**导入**  
 — 定时增量同步上游 nuclei-templates，也可手动触发或按条件拉取入库。模板汇总在 data/nuclei_tpl/  
，可直接 nuclei -l  
 执行。  
```
curl localhost:8100/api/nuclei/sync                                  # 同步状态curl -X POST localhost:8100/api/nuclei/sync                          # 手动触发增量同步curl 'localhost:8100/api/nuclei/remote?limit=20&severity=critical'  # 预览，不落盘curl -X POST localhost:8100/api/nuclei/pull -d '{"limit": 20}'      # 拉取入库
```  
## 接入新漏洞源  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/WibL3bOeESMLNkT2cwk80ibmTsuXgQ1XlnjVd2zpvib6QiaUYNHRMhibkxx3GZ1qib0QOM8RkjRicAqxQT9t91svZNH98xPbIr5IyXicClAzejh4UAU/640?wx_fmt=webp&from=appmsg "")  
  
设置页填一个社区首页即可，系统自动完成探测与判活：先按常见路径（/feed  
、/rss  
、/rss.xml  
、/atom.xml  
 …）逐个试，解析得出条目的即为 feed；��[...]  
```
# 探测（不写配置，先看结果）curl -X POST localhost:8100/api/sources/discover \  -H 'Content-Type: application/json' -d '{"url": "https://xz.aliyun.com"}'# 接入（name 唯一，重复即视为更新）curl -X POST localhost:8100/api/sources \  -H 'Content-Type: application/json' \  -d '{"name": "先知", "url": "https://xz.aliyun.com/feed", "enabled": true}'# 查看已接入的源 / 移除curl localhost:8100/api/sourcescurl -X DELETE localhost:8100/api/sources/先知
```  
  
几点说明：  
- **内置源与自定义源叠加抓取**  
，自定义源每轮现读配置，改完不用重启。  
  
- **AI 判活不可用时**  
自动退化为标题关键词匹配，宁可放过也不误杀——把正常社区挡在门外的代价远高于放进一个无关站点。  
  
- **JS 渲染的站点**  
探测不到 feed（页面由脚本生成），可先在浏览器里找到它的 RSS 地址再直接填进上面的 POST /api/sources  
。  
  
- **平台型 API**  
（OSV / GitHub Advisory / NVD 这类 JSON 接口）暂未实现，扩展点见 source_discovery.py  
 末尾的 _API_ADAPTERS  
。
