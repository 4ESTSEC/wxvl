#  【安全圈】电商平台前员工利用系统漏洞，0元购3000多件家电  
 安全圈   2026-08-08 11:00  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/aBHpjnrGylgOvEXHviaXu1fO2nLov9bZ055v7s8F6w1DD1I0bx2h3zaOx0Mibd5CngBwwj2nTeEbupw7xpBsx27Q/640?wx_fmt=other&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1&wx_co=1 "")  
  
  
**关键词**  
  
  
  
系统漏洞  
  
  
今年5月底，某电商平台突然发现不对劲：后台一大批“以旧换新”订单显示旧家电根本没人回收，新机却一笔接一笔往外发，实付金额全是0元。一查吓一跳，光异常订单就有3711笔，按进货价算平台亏了169万。这些收货地址全都写得模棱两可，收件人也是代号，顺着账号往回捋，86个号最后都缠到同一个人身上——曾在平台售后岗干了三年的离职员工张某。  
  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/sbq02iadgfyEs6shr7JxzTo3fJEAT4W72hXyic5aOicaunpXBymw9CXCj4x3BgMx84KbwVpO1nxNXmOhNSW97adqibv0WGH8wB2OdZY7WkWPwLA/640?wx_fmt=jpeg&from=appmsg "")  
  
  
民警敲门那天，张某家里已经像个快递中转站，客厅、厨房、过道全是没拆封的纸箱，当场清出166件全新家电，还有22件已经拆了在家用上了。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/sbq02iadgfyFL8Xkn8hLbOApqicM9Wqibu04B69Pcibeticza4ibFD9iaia5mBdw535LpLh7icve2Aq8ZXcjWMXGE9ImMk59MaQyQ1Y5gEvMicD6ibU1OM/640?wx_fmt=jpeg&from=appmsg "")  
  
  
这还不算完，她在附近还租了个近600平的仓库，里面码着近千台新机，冰箱洗衣机摞得整整齐齐，民警花了8个小时才点完数。  
  
  
张某本来就是个爱琢磨优惠的“羊毛党”，离职后对老东家的系统流程门儿清。她发现一个隐蔽漏洞：先选个大件空调走以旧换新，系统刚出估价就立刻取消，再切去下单几十块的煮蛋器，趁系统没反应过来马上切回大件订单——这时候页面一刷新，小家电直接变成0元，旧机也不用交。靠这套“手速流”，她拉上爸妈、老公、亲戚，连还没离职的前同事账号都借来用，疯狂下单，转头就按市价八折挂二手平台甩货变现。  
  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/sbq02iadgfyERSZVbBBdHA0IhxUiajtoqVWAPRRBbkdFyDib5woFMvd8aboJfhu6F0r4CZiaX7D2a79BjvaaPsH4PiaJes46Fbbh1A4fVynbzCvE/640?wx_fmt=jpeg&from=appmsg "")  
  
  
两个前同事察觉她不正常，没想着劝，反而追着问“怎么弄的”，被敷衍之后就开口要电器、要现金当封口费。警方说得很明白：没动手刷单，但明知道是偷还分赃，一样算共犯。  
  
  
目前张某等三人因涉嫌盗窃罪已经被刑拘，其他人退了赃，平台那边也把那个“时间差漏洞”补上了。办案民警顺带补了一句大实话：别把Bug当福利，薅着薅着，刑拘通知书就比快递先到家了。
