# 一、AppSecret密钥泄露漏洞  
  
AppSecret是小程序的唯一凭证密钥，也是获取小程序全局唯一后台接口调用凭证（access_token）的重要参数，需要开发者妥善保管至后台服务器中，并严格保密，不向任何第三方等透露。小程序若存在AppSecret密钥泄露漏洞的情况，会造成身份信息仿冒、敏感数据外泄等严重后果，开发者应及时发现该漏洞并快速修复相应问题。  
  
实战案例   
  
某小程序因为AppSecret泄露，导致攻击者可以通过调用API获取该小程序敏感数据，如接口调用凭证、用户信息、用户使用数据等，造成了极大的安全风险。  
  
通过以下展示我们可以明晰该小程序敏感数据外泄的原因，测试者先对小程序网络请求进行抓包，发现请求响应中包含了appid和AppSecret敏感信息：

# 二、任意用户访问  
  
微信小程序登录的时候会产生一个临时code 请求服务器进行访问  
  
![](https://mmbiz.qpic.cn/mmbiz_png/0ic45F94NibRt59gibWZdc9nseFmwamr08jr0lK3xLNuX6IhZXvQCXfdVBPbfmwc2nu5z9NtQRuLNX9O9kBfpylseWicVLFdvFOVuwtXGb457FI/640?wx_fmt=png&from=appmsg "")  
  
删除code再进行访问 还是可以访问  并且返回用户相关信息 所以code并没作用  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/0ic45F94NibRtNVZmRNP3PlLqcLibqCJcTHHpYMic9VexoxMKlPE6GgM7PqgqlkeIhb0vTQWmzLYBAGUADYS1KicjcRro1pK9ZzpswBc2FJlyn9g/640?wx_fmt=png&from=appmsg "")  
  
而且访问该id 还会产生jwt token 这个一般是用来身份验证的  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/0ic45F94NibRuKtwsZ4cPY6a1LNNww4K8h5SibXxZNDxjrtL5ehF9FtOk0jln1Na5vgAq7vbqLpoEGBWCc7tylziaRHChX1F9pMINnSnCrsMRcc/640?wx_fmt=png&from=appmsg "")  
  
对id进行遍历 获取多个用户的token  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/0ic45F94NibRtSxEuZGkcmJ01DW4pJlh103kHdia7PqqL1CicDibB72VXdvSmuBxjzhkOmrdjWVGXBVEg9kibqZP2pN7xHZmvK5TyRnLicYx3SFv2g/640?wx_fmt=png&from=appmsg "")
