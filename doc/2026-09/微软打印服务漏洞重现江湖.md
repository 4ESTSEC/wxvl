#  微软打印服务漏洞重现江湖  
原创 打印机安全
                    打印机安全  打印机安全   2026-09-17 07:20  
  
近日，关于微软打印服务（Windows  Print Spooler Components）的两个漏洞重现江湖，2021年的PrintNightmare漏洞留下的腥风血雨还未散尽，旧日伤疤还未痊愈，  
镇守主机城门的老衙役"spoolsv.exe"再次中刀。  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/6liaItc9B4Z9ibjRw4LgdnBI0gjMdtThmzYOCEnLADcQrlbiaHVcUSpDKa77u1N9GskNOVL9IjtX84CIaxPJqJnaFpLWQPoN0fCU3aLkbtOlvI/640?wx_fmt=jpeg "")  
  
皆因老衙役  
"spoolsv.exe"手握系统最高权限，江湖刺客均以攻破其城门为炫技。两个漏洞武功略有差距，其一须已登入内院，再递上畸形笺纸，撑破衙役体内内存经脉，就地夺权；其二更为凶险，无需踏入宅院、无需任何身份凭证，隔着网络递去特制畸形打印笺，笺内藏毒，一经解析便撕裂衙役堆内存经脉，远程即可注入杀招、夺舍执行任意代码。  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/6liaItc9B4Z9opGADaC6uPgNN7iaJdhLMiaMdqDtq1XJANCkic8zibvjPk7JDbNdU8rVgrgTibErQ4JbK3QTPAZCbZ0STskz0CAgPbyHoicYrbfGdE/640?wx_fmt=other&from=appmsg "")  
  
两个漏洞分别编号：CVE-2026-70564（评分7.8），CVE-2026-85877(评分8.8）影响系统包括win10、win11的某些版本。  
  
![](https://mmbiz.qpic.cn/mmbiz_png/6liaItc9B4ZibCz9Gkgql3d5s0pQALvw5PovGCrE5867ZZ1ItQYZwaSqT7TWDNibrH1ibcOUv8hN9VLyaictg0FYVvJsgL7jKkyGqXkeRooq3vb4/640?wx_fmt=png&from=appmsg "")

本地打印者或者局域网共享打印者都可以把运行有Spooler服务的电脑攻破。
