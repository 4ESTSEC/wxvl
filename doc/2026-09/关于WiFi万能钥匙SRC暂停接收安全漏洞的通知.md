#  关于WiFi万能钥匙SRC暂停接收安全漏洞的通知  
 WiFi万能钥匙安全应急响应中心   2026-09-28 09:49  
  
   
  
#   
  
尊敬的白帽师傅：  
  
为进一步提升WiFi万能钥匙SRC平台的服务能力及使用体验，近期我们将对平台进行升级优化。  
  
自公告发布之时起，WiFi万能钥匙SRC将暂停接收安全漏洞，具体恢复时间将另行通知。升级期间请勿对南京尚网网络及WiFi万能钥匙相关业务进行安全测试。  
## 升级期间相关说明  
- • **已提交漏洞**  
：将继续按照现有流程正常审核及处理。  
  
- • **新漏洞提交**  
：暂停接收，提交入口暂时关闭。  
  
- • **积分及兑换**  
：正常进行，不受本次升级影响。  
  
升级期间，如发现可直接获取业务系统服务器权限的RCE漏洞（不含客户端RCE），可通过WiFi万能钥匙官方安全邮箱（sec@wifi.com）与我们联系。我们将根据漏洞的实际价值，参照平台相关规则予以奖励。除上述类型以外的其他漏洞，请勿通过邮件提交，我们将不予受理。  
  
感谢各位白帽师傅的理解与支持！
