#  聚铭网络受邀出席2026VARA大会，获评AIVD优秀技术支撑单位并入选人工智能安全漏洞治理联盟  
 聚铭网络   2026-09-22 10:30  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_gif/uaicMoGl6iaSz34icEtlMpNrZxACe3gTguJiahs3ias2D2kS6ozGicAjicWicluQ1LHzMVaFmAuGP4ibdB4nJY8Y1Dmxgcg/640?wx_fmt=gif "")  
  
9月22日，由中国信息安全测评中心主办的第十六届网络安全漏洞分析与风险评估大会（VARA）在重庆盛大启幕。大会以“数智拓远 善治久安”为主题，汇聚政企学研多方力量，围绕人工智能安全治理、网络安全风险防控等核心议题展开深度交流，助力完善国家级数智安全治理体系。  
  
聚铭网络受邀出席本次重磅行业盛会，凭借在AI漏洞治理领域的扎实技术积累与年度突出工作成果，一举斩获两项国家级权威认可——  
获评  
“  
2026年度国家人工智能安全漏洞库优秀技术支撑单位  
”，并入选“  
人工智能安全漏洞治理联盟成员单位”，  
充分彰显了公司在AI安全领域的专业能力与行业地位。

**技术突破**  
  
  
  
**荣获AIVD优秀技术支撑单位**  
  
  
  
随着人工智能产业高速发展，AI应用场景不断拓宽，新型、隐性安全漏洞持续增多，行业对专业化、体系化的漏洞研判与风险治理能力需求愈发迫切。为针对性补齐AI安全治理短板，国家信息安全漏洞库（CNNVD）  
于2026年4月专项设立国家人工智能安全漏洞库（AIVD），聚焦人工智能领域漏洞收集、研判、分析与治理，是国内AI安全漏洞领域的核心国家级权威平台。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/aKicBJwHBSq4nENSIzQOYHLibl8Rq50FDxbJGFUiaOHxVjXibQEZfBpotb1EzPEyqdrXXBjBTjiamWHjAa05ye9pKxvoxR79BwIibyBgDmU6iaqKqE/640?wx_fmt=jpeg&from=appmsg "")  
  
  
本次大会上，AIVD正式发布技术支撑单位合作计划，并公布首批支撑单位名单。凭借2026年度在AI漏洞常态化研判、漏洞验证分析、安全技术支撑、风险应急处置等工作中的优异表现，  
聚铭网络荣获“2026年度国家人工智能安全漏洞库优秀技术支撑单位”，成为全国仅  
20家入选企业之一。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/aKicBJwHBSq4blx8ib5HY8VwY5PvuM3zdJb3Po1CHYeTSPA2KTUtibDx46HAxiaguwYiatKVNhw0FnL6eRhjgiaxG3FYJ5e9SPgiaZ3zwuT6uKIBibc/640?wx_fmt=jpeg&from=appmsg "")  
  
  
  
**生态协同**  
  
  
  
**入选人工智能安全漏洞联盟**  
  
  
  
在同日召开的人工智能漏洞研究与治理分论坛上，由CNNVD牵头组建的  
人工智能安全漏洞治理联盟举行第二批成员单位授牌仪式。经严格遴选，聚铭网络成功入选联盟成员单位，正式融入国家级AI安全漏洞协同治理生态。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/aKicBJwHBSq6tP9Er5AcVgFw79MmSY1cHHQlWzN3kJdK7O5licjutPcMZa4lp9qjRVOTnhHCkZb6ibct2EMEvHG0HyPu7gIqfibZlDfsyaaohAo/640?wx_fmt=jpeg&from=appmsg "")  
  
  
公司将严格遵守《人工智能安全漏洞治理联盟章程》，依托联盟平台，积极参与漏洞联合检测、评估验证、信息共享、应急响应与协同处置，推动人工智能漏洞治理技术创新、标准完善、人才培养、成果转化与行业交流合作。  
  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/aKicBJwHBSq4Z2JFvt7wAqD2TfZCrXjfR9gyAcAaHqFPBlzyZSM9DjzSOdWlsMKruypMiaQf9tj3ZTT2q0C1rVodBumicaS8Y4EGE3Fc00cYibo/640?wx_fmt=jpeg&from=appmsg "")  
  
  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/aKicBJwHBSq4ibW5A4OBiaPv7lphd5wPNQtfjyrmFV5jwmRiawxbL0oib0ReHgeEyhWBFI2rkGicKzTbceR6HpzIQormBSfdW3oiboH4PhicDbYiaWNk/640?wx_fmt=png&from=appmsg "")  
  
数智拓远，安全为基；善治久安，协同为要。当前，人工智能越向纵深发展，漏洞治理越需要体系化协同。此次双项荣誉的背后，是聚铭网络长期深耕AI+网络安全领域的沉淀与坚守。  
  
未来，聚铭网络将继续发挥在漏洞治理、安全运营、威胁分析等方面的专业积累，深度融入国家AI安全治理大局，与政企学研各方同向发力，共同筑牢智能时代的安全底座，护航数字产业行稳致远。
