#  【已复现】WordPress 核心主题预览缺陷可导致RCE漏洞（Click2Shell）  
原创 360漏洞研究院
                    360漏洞研究院  360漏洞研究院   2026-09-19 06:54  
  
WordPress 核心主题预览功能存在安全缺陷，特制链接可触发主题自动安装和预览。  
  
  
漏洞被命名为 Click2Shell。攻击者无需拥有站点账号，但需要诱导已登录且具备主题安装权限的管理员访问恶意链接。与第三方主题漏洞结合后，可实现服务器端 PHP 代码执行。  
  
  
**利用前置条件：**  
- 管理员已登录 WordPress 后台，并访问攻击者构造的链接（UI:R）  
  
- 目标站点 WordPress 版本低于 7.1.1  
  
目前 **360漏洞挖掘智能体已成功复现该漏洞**  
。本文包含完整影响范围、正式修复方案、技术原理与复现细节。

**01**  
  
**漏洞影响范围**  
  
  
  
受影响的 WordPress 核心版本：  
  
WordPress < 7.1.1  
  
  
**02**  
  
**修复建议**  
  
  
  
**正式防护方案**  
  
升级 WordPress 至 7.1.1 或更高版本。  
  
  
**03**  
  
**漏洞描述**  
  
  
  
近日，安全研究团队公开了 WordPress 核心中的一处主题预览漏洞，并将其命名为 Click2Shell。主题预览逻辑将 URL 中的主题标识未经适当转义拼接到 jQuery 选择器中，攻击者可改变选择目标，使页面自动触发安装操作。官方补丁对输入进行选择器转义，并限制匹配对象为主题卡片。  
  
  
核心缺陷能够安装攻击者指定的 WordPress.org 官方目录主题。研究方通过 Mobile Repair Zone 2.5.4 主题演示了后续攻击：未启用的主题仍可在预览时加载，其插件安装接口缺少 nonce 和权限校验，进而被用于加载攻击者提供的 PHP。代码以站点 PHP 进程权限执行，可能导致站点数据泄露、内容篡改及站点被接管。  
  
  
**04**  
  
**漏洞复现**  
  
  
  
360 漏洞研究院已成功复现 WordPress 主题预览注入漏洞（Click2Shell），构造并发送对应 Payload，成功验证该漏洞可导致远程代码执行，最终获取到目标站点 Shell 权限。
