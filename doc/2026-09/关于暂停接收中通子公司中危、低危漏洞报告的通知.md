#  关于暂停接收中通子公司中危、低危漏洞报告的通知  
 中通安全应急响应中心   2026-09-11 07:44  
  
![](https://mmecoa.qpic.cn/mmecoa_png/YNV6vXA3o4YILZeBlGjliaEu1O12x6icIV6MZAh9QkHbC652wL4Kn8d4kMmc5aBxdmU3BIgyDCYslMRGUPdpVM76WLhuzc9uA0ryNoEgOGrIk/640?wx_fmt=png&from=appmsg "")  
  
为集中资源处理高风险安全隐患，提升漏洞处置效率，经ZSRC团队评估决定：**暂停接收中通旗下子公司中危、低危漏洞报告**  
。包括但不限于：兔喜、中通快运、中通国际、中通云仓、中通冷链、中通支付、中通智运、中通金融等。  
  
  
**本公告****自****发布之日起立即生效：**  
公告发布前已提交、尚未完成评审的子公司中危、低危漏洞，仍按原有规则处理，本公告发布后提交的中危、低危漏洞，均不收取。
