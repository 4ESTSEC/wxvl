1. IBM Guardium Data Protection 跨站脚本漏洞（CNNVD-2026-85700769）  
  
IBM Guardium Data Protection是美国IBM公司的一款防止敏感数据泄露与丢失的数据安全防护软件。  
  
IBM Guardium Data Protection 12.2版本存在跨站脚本漏洞，该漏洞源于对用户的输入中和不当，攻击者利用该漏洞可以执行任意代码。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://www.ibm.com/support/pages/node/7288040  
  
2. Dell OpenManage Server Administrator 授权问题漏洞（CNNVD-2026-45982761）  
  
Dell OpenManage Server Administrator是美国Dell公司的一款服务器管理及监控软件。  
  
Dell OpenManage Server Administrator 11.1.0.3之前版本存在授权问题漏洞，该漏洞源于关键功能缺少身份验证，攻击者利用该漏洞可以远程执行任意代码。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://www.dell.com/support/kbdoc/en-us/000506586/dsa-2026-403-security-update-for-dell-openmanage-server-administrator-omsa-network-access-vulnerabilitiesv  
  
3. Google Chrome 资源管理错误漏洞（CNNVD-2026-74975972）  
  
Google Chrome是美国Google公司的一个跨平台Web浏览器。  
  
Google Chrome 153.0.8010.47之前版本存在资源管理错误漏洞，该漏洞源于内存释放后重用，攻击者利用该漏洞可以通过特制HTML页面在沙箱内执行任意代码。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://chromereleases.googleblog.com/2026/09/stable-channel-update-for-desktop_0541751186.html

1. IBM Langflow OSS 命令注入漏洞（CNNVD-2026-30234359）  
  
IBM Langflow OSS是美国IBM公司的一款可视化构建AI工作流的低代码工具平台。  
  
IBM Langflow OSS 1.0.0版本至1.11.5版本存在命令注入漏洞，该漏洞源于对操作系统命令中使用的特殊元素中和不当，攻击者利用该漏洞可以执行任意操作系统命令。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://www.ibm.com/support/pages/node/7286666  
  
2. Tencent WeKnora 服务端请求伪造漏洞（CNNVD-2026-88818381）  
  
Tencent WeKnora是中国Tencent公司开源的一个基于LLM的框架,具有使用RAG范式进行深度文档理解、语义检索和上下文感知答案等功能。  
  
Tencent WeKnora 0.5.2版本至0.7.0之前版本存在服务端请求伪造漏洞，该漏洞源于POST /api/v1/knowledge-bases/:id/knowledge/url端点在下载用户提供的URL文档时未重新验证HTTP重定向目标，攻击者利用该漏洞可以访问内部服务和云元数据。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://github.com/Tencent/WeKnora/releases  
  
3. vLLM 资源管理错误漏洞（CNNVD-2026-98830536）  
  
vLLM是一个开源的适用于LLM的高吞吐量和内存高效推理和服务引擎。  
  
vLLM 0.28.0之前版本存在资源管理错误漏洞，该漏洞源于内存过度分配，攻击者利用该漏洞可以导致API服务器进程崩溃。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://github.com/vllm-project/vllm/security/advisories/GHSA-99f2-hwrc-gvq8
