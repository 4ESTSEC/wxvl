#  微软发布补丁修复了974个漏洞，其中包括两个已被利用的Windows零日漏洞  
Rhinoer
                    Rhinoer  犀牛安全   2026-09-17 16:00

微软周二打破了“补丁星期二”的记录，修复了其软件产品组合中惊人的974 个漏洞，其中包括两个据称已被实际利用的漏洞。  
  
其中包括 Windows 系统中的 723 个漏洞、Office 和 Office 2016 中的 111 个漏洞、SQL 数据库中的 62 个漏洞以及开发者工具中的 22 个漏洞。其中，超过 110 个漏洞被评为严重级别。权限提升、远程代码执行和信息泄露这三种主要漏洞类型占本月修复漏洞总数的近 90%。加上微软修复的 25 个非微软 CVE 漏洞，此次更新使已修复的漏洞总数达到 999 个。  
  
9 月份创纪录的安全更新是在微软 8 月份修复了457 个漏洞、7 月份修复了 663 个漏洞、6 月份修复了 220 个漏洞、5 月份修复了 161 个漏洞之后进行的。  
  
Action1漏洞研究总监杰克·比瑟表示： “在这种规模下，挑战不仅在于完成补丁列表，更在于了解哪些漏洞需要优先处理。由于数百个更新同时发布，IT和安全团队需要迅速区分哪些漏洞需要立即采取行动，哪些漏洞可以按照正常的部署流程进行处理。”  
  
以下列出了两个已被积极利用的漏洞——  
- **CVE-2026-85880**（CVSS评分：7.8）- Windows高级本地过程调用（ALPC）中基于堆的缓冲区溢出漏洞，允许授权攻击者在本地提升权限并获得SYSTEM权限。  
- **CVE-2026-81963**（CVSS评分：7.8）- Windows 更新堆栈中存在不正确的链接解析漏洞，允许授权攻击者在本地提升权限并获得 SYSTEM 权限。  
微软在针对 CVE-2026-85880 的安全公告中表示：“攻击者如果能够在低权限的应用程序容器中执行代码，就可以利用此漏洞在本地逃逸沙箱，并提升受影响系统的权限。无需用户进行任何额外交互。”  
  
  
Rapid7 的首席软件工程师 Adam Barnett 表示，所有受支持的 Windows 版本都将收到针对 CVE-2026-81963 的补丁，此举“大概是为了加强控制，防止 Windows 更新堆栈跟随恶意链接，并用攻击者控制的冒名顶替者覆盖系统组件”。  
  
网络安全公司 Volexity 和 Proofpoint 因报告 CVE-2026-85880 而受到表彰，而空中客车直升机公司的攻击性安全研究员 Romain Deperne 和微软威胁情报中心 (MSTIC) 则因发现第二个漏洞而受到赞扬。  
  
Windows 制造商表示，他们已经检测到针对这些漏洞的零日攻击，但没有透露幕后黑手是谁、攻击规模有多大，以及这些攻击是否成功入侵了任何受害者。  
  
根据漏洞管理和评估平台 Tenable 的数据，自 2022 年以来，Windows 更新堆栈中已发现七个权限提升漏洞。然而，CVE-2026-81963 是第一个零日漏洞，也是第一个被实际利用的漏洞。至于 CVE-2026-85880，它是继 CVE-2023-21674 之后第二个被用作零日漏洞的漏洞，而CVE-2023-21674已于 2023 年 1 月得到修复。  
  
这一事态发展促使美国网络安全和基础设施安全局 (CISA) 将这两个漏洞添加到其已知利用漏洞 ( KEV ) 目录中，要求联邦民事行政部门 (FCEB) 机构在 2026 年 9 月 22 日之前应用这些修复程序。  
  
微软修复的其他一些值得注意的缺陷如下：  
- **CVE-2026-55007**（CVSS评分：8.1）——Microsoft Exchange Server 中的一个双重释放漏洞，允许未经授权的攻击者通过网络执行代码。  
- **CVE-2026-80097**（CVSS评分：8.6）- Microsoft Authenticator 中存在身份验证漏洞，允许未经授权的攻击者在本地提升权限。  
- **CVE-2026-69465**（CVSS评分：8.8）——Microsoft Office SharePoint 中存在一个缺少授权的漏洞，允许已授权的攻击者通过网络执行代码。  
- **CVE-2026-65669**（CVSS评分：9.6）- SQL Server 中的一个注入漏洞允许未经授权的攻击者通过该漏洞提升网络权限。  
- **CVE-2026-69525**（CVSS评分：9.8）——Windows远程桌面服务中的一个释放后使用漏洞，允许未经授权的攻击者通过网络执行代码。  
- **CVE-2026-69595**（CVSS评分：9.8）- Windows Services for NFS ONCRPC XDR Driver 中存在释放后使用漏洞，允许未经授权的攻击者通过网络执行代码。  
- **CVE-2026-69730**（CVSS评分：9.8）——Windows DNS 服务器中的一个释放后使用漏洞，允许未经授权的攻击者通过网络执行代码。  
- **CVE-2026-69829**（CVSS评分：9.8）——Windows Shell 中的一个基于堆的缓冲区溢出漏洞，允许未经授权的攻击者通过网络执行代码。  
- **CVE-2026-72979**（CVSS评分：9.8）——Windows DHCP服务器中的一个释放后使用漏洞，允许未经授权的攻击者通过网络执行代码。  
根据 TrendAI 的零日漏洞计划 (ZDI) 的数据，仅今年一年，微软就修复了2760 个安全漏洞，这表明人工智能 (AI) 辅助发现漏洞的速度不太可能很快放缓。  
  
Tenable 高级研究工程师 Satnam Narang 在一份与 The Hacker News 分享的声明中表示：“9 月的‘周二补丁日’发布标志着‘周二补丁日’历史上的另一个转折点，因为本月修复了近 1000 个 CVE（964 个），这是 2026 年创下的另一个新纪录。”  
  
从背景来看，本月的‘周二补丁日’比 7 月份创下的前纪录（569 个）增加了近 70%，使今年的总数超过 2600 个，这已经是 2020 年创下的前纪录（1245 个）的两倍多，而且还有三个月的时间。  
  
尽管发布了大量补丁，但预计会影响大多数组织的漏洞数量仍然相当少，更不用说目前为止活跃漏洞利用的数量并未出现相应的激增。纳朗补充说，对于组织而言，至关重要的是要了解哪些漏洞实际影响到自身，这些漏洞是否会因可通过互联网访问和利用而构成威胁，并根据这种风险情况确定修复的优先级。  
  
Fortra 安全研发副总监 Tyler Reguly 说：我认为可以肯定地说，只要微软在修复漏洞方面还在追赶进度，这些数字就已经失去了所有意义。  
  
这并非微软独有的问题。我们在Oracle和其他一些积极主动的大型厂商那里也看到了同样的问题。我们需要记住，大量的CVE编号是一件好事，因为这有助于在攻击者有机会发现并利用漏洞之前缩小攻击面。最终，所有那些长期存在、难以发现的漏洞都将被修复，‘补丁星期二’也将恢复其正常的更新频率。”
