#  惠普修复 HPLIP 严重漏洞  
sec随谈
                    sec随谈  sec随谈   2026-09-18 01:07  
  
惠普发布安全更新，修复了其官方 Linux 打印套件中的十个安全缺陷。这些漏洞允许远程攻击者在无需身份验证的情况下执行任意代码或触发拒绝服务攻击。因此，运行 Linux 桌面环境的组织必须立即将 HPLIP 更新至 3.26.6 版本。  
  
**为何此威胁至关重要**  
  
据估计，数百万台 Linux 工作站和打印服务器依赖 HPLIP 驱动程序提供硬件支持。由于打印后台程序通常处理来自网络的不受信任文档，打印堆栈中的软件缺陷会带来重大安全风险。一旦攻击者利用这些漏洞，便可控制核心系统进程，未经授权的用户还可将本地权限提升至 root 并修改关键系统配置文件。  
  
**攻击方式**  
  
上述安全缺陷存在于打印软件的多个驱动程序和解析库中。根据安全公告，"这些发现影响多个软件组件，在特定条件下可能导致远程代码执行、权限提升、拒绝服务、信息泄露或未经授权的文件修改。"  
  
网络攻击者无需提供有效凭证，即可向存在漏洞的端点发送精心构造的打印请求。CVE-2026-91106 和 CVE-2026-91104 等漏洞可触发内存损坏，CVSS 4.0 评分均为 9.3。此外，本地攻击者可利用缓冲区缺陷将任意文件写入受限位置。目前，惠普确认上述漏洞均无在野利用案例或公开的概念验证利用代码。  
  
**受影响版本**  
  
上述 HPLIP 漏洞影响所有受支持 Linux 发行版上低于 3.26.6 版本的所有软件版本。  
  
**补丁与缓解措施**  
  
管理员应立即将打印软件包更新至 HPLIP 3.26.6 或更高版本，可通过发行版软件包管理器或厂商门户直接下载最新安装包。如需进一步指导，请查阅惠普官方安全公告。此外，管理员还应将网络打印机隔离在专用管理子网中，以降低风险敞口。
